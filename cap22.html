Structura Spermatozoidului Uman — SVG interactiv

Caracteristici esențiale — Admitere

🔵 Componentele spermatozoidului Cap: nucleu condensat, 23 cromozomi (haploid). Acrozom pe polul anterior → enzime fertilizare.

Gât: scurt, cu centrioli.

Piesă intermediară: mitocondrii în spirală → ATP pentru mișcare.

Coadă (flagel): axonemă (9+2 microtubuli) + înveliș fibros → propulsie.
⚡ Numere cheie Ejaculat normal: 2–5 ml
Concentrație: 20–100 milioane/ml
Motilitate normală: >50%
Morfologie normală: >30%
Oligospermie: <15 mil/ml
Azoospermie: lipsă completă
🧬 Reacția acrozomală Când spermatozoidul contactează zona pellucida → enzimele acrozomale sunt eliberate → dizolvă zona → fuziunea cu membrana ovocitului → fertilizare. Fără reacție acrozomală = infertilitate masculină.
💡 Memotehnic — Segmentele spermatozoidului
„Cap Gâtul Piesei intermediare Coada"
Cap = Cromozomi + aCrozom
Gât = Gentrioli
Piesă intermediară = Putere (ATP, mitocondrii)
Coadă = Conduces spermatozoidul

💡 Diferența cheie MEIOZA I vs II
Meioza I = reducțională — scade numărul de cromozomi (2n→n), centromerii NU se divid, are loc crossing-over în profaza I (variabilitate genetică!).
Meioza II = ecuațională — similară mitozei, centromerii SE DIVID, nu se schimbă numărul de cromozomi, nu are loc replicare ADN în interfaza II!

Mecanismul erecției și ejaculării — Control nervos

Erecția — Controlul parasimpatic

1
Stimulare sexuală
Stimuli psihogeni (cortex) sau reflexogeni (locali)
›
Cortexul cerebral poate iniția erecția prin gânduri, imagini (psihogenă). Sau direct prin stimularea organelor genitale (reflexogenă) → impulsuri aferente → centri medulari sacrali S2-S4.
2
Impulsuri parasimpatice (S2-S4)
Nervii erigentes → dilatare arteriole penis
›
Sistemul nervos PARASIMPATIC (centrul sacral S2-S4) → nervii cavernosi → eliberare NO (oxid nitric) → relaxare musculatură netedă arteriolare → vasodilatație masivă → creștere flux sanguin în corpii cavernoși și spongios.
3
Umplerea sinusoidelor vasculare
Sânge → corpii cavernoși → turgescență
›
Sinusoidele din țesutul erectil se umplu cu sânge. Presiunea crescută COMPRIMĂ venele de drenaj (mecanism veno-ocluziv) → sângele rămâne captiv → erecție. Inhibitorii de PDE5 (sildenafil) mențin NO → facilitează erecția.

Ejacularea — Controlul simpatic

1
Emisie (simpatic)
Spermă → uretră → sfincterul intern se închide
›
Sistemul nervos SIMPATIC (centrul toracolombar T12-L2) → contracții musculare duct deferent + vezicule seminale + prostată → propulsia spermei în uretra prostatică. Sfincterul intern (neted) se ÎNCHIDE → împiedică ejacularea retrogradă în vezică.
2
Ejacularea propriu-zisă
Contracții ritmice muschi bulbospongios → expulzie
›
Reflexul ejaculator = contracții ritmice ale musculaturii scheletice (bulbospongios, ischiocavernos) → expulzia spermei prin orificiul uretral extern. Inervație somatică (nervul pudendal).
3
Detumescența
Vasoconstricție simpatică → refluarea sângelui
›
Post-ejaculare: simpatic → vasoconstricție arteriole → ↓ flux sanguin → venele se deschid → sânge evacuează din sinusoide → penis flasc. Stimulii simpatici persistenți mențin starea flască.
🎯 Esențial — Controlul nervos dual Erecție = PARASIMPATIC (S2-S4) — „NO = Love" — Vasodilatație. Mnemonic: Point = Parasimpatic
Ejaculare = SIMPATIC (T12-L2) — Contracții propulsive. Mnemonic: Shoot = Simpatic

1. Care este temperatura necesară în scrot pentru spermatogeneză normală față de temperatura corpului?

A Cu 5-7°C mai scăzută
B Cu 2-3°C mai scăzută ✓
C Egală cu temperatura corpului
D Cu 1°C mai ridicată
✅ Corect! Scrotul menține testiculele la ~34-35°C, cu 2-3°C sub temperatura corpului (37°C). Temperatura crescută → inhibă spermatogeneza → infertilitate. Aceasta explică de ce criptorhidia (testicul necoborât) cauzează infertilitate.
❌ Greșit. Temperatura scrotală este cu 2-3°C mai scăzută decât temperatura corpului. Aceasta este esențială pentru spermatogeneză normală.

2. Câte spermatozoizi rezultă dintr-un singur spermatocit primar?

A 1
B 2
C 4 ✓
D 8
✅ Corect! Un spermatocit primar (2n) → Meioza I → 2 spermatocite secundare (n) → Meioza II → 4 spermatide (n) → Spermiogeneză → 4 spermatozoizi. Spre deosebire de ovogeneză unde un ovocit primar produce doar 1 ovul + 3 globule polare.
❌ Greșit. Un spermatocit primar produce 4 spermatozoizi: Meioza I → 2 spermatocite secundare → Meioza II → 4 spermatide → 4 spermatozoizi.

3. Ce celule testiculare produc testosteron și sunt stimulate de LH?

A Celulele Sertoli
B Celulele Leydig (interstițiale) ✓
C Spermatogoniile
D Celulele mioide peritubulare
✅ Corect! Celulele Leydig (interstițiale) se găsesc între tubii seminiferi, sunt stimulate de LH → produc testosteron. Celulele Sertoli sunt stimulate de FSH și produc inhibina + ABP.
❌ Greșit. Celulele Leydig (interstițiale) produc testosteron sub stimulul LH. Celulele Sertoli sunt sustentaculare (FSH → inhibina).

4. Care glandă contribuie cu ~60% din volumul lichidului seminal?

A Prostata
B Vezicula seminală ✓
C Glandele bulbouretrale
D Testiculele
✅ Corect! Vezicula seminală = 60%, Prostata = 30%, Gl. Bulbouretrale = 5%, Testicule (spermatozoizi) = 5%. Vezicula seminală secretă fructoză (nutriție spermă) + prostaglandine + lichid alcalin.
❌ Greșit. Vezicula seminală contribuie cu ~60% din volumul seminal. Prostata = ~30%. Reține: Vezicula → cel mai mare volum + fructoză.

5. Care structură este responsabilă pentru MATURAREA spermatozoizilor și le conferă mobilitate?

A Tubii seminiferi
B Epididimul ✓
C Ductul deferent
D Prostata
✅ Corect! Epididimul este locul de maturare a spermatozoizilor (~2 săptămâni). Spermatozoizii intră imobili și ies MOBILI. Funcții: maturare, stocare, transport, resorbția spermatozoizilor deteriorați.
❌ Greșit. Epididimul este locul de maturare. Tubii seminiferi = producție; Ductul deferent = transport; Prostata = secreție lichid alcalin.

6. Ce enzime conținute în acrozomul spermatozoidului sunt esențiale pentru fertilizare?

A Hialuronidaza + enzime proteolitice (penetrare zona pellucida) ✓
B ATP-sintetaza
C Reductaza și hidrolaza lizozomală
D Trombokinsaza
✅ Corect! Acrozomul = structură derivată din Golgi pe capul spermatozoidului. Conține hialuronidaza (dizolvă coroana radiata) + acrozina și enzime proteolitice (penetrează zona pellucida). Reacția acrozomală = eliberarea acestor enzime.
❌ Greșit. Acrozomul conține hialuronidaza + enzime proteolitice → penetrarea straturilor ovocitului. ATP-sintetaza = mitocondrii (piesa intermediară).

7. Ce hormon exercită feedback negativ SELECTIV pe FSH (nu și pe LH)?

A Testosteronul
B Estrogenul
C Inhibina ✓
D GnRH
✅ Corect! Inhibina, secretată de celulele Sertoli, exercită feedback negativ SELECTIV pe FSH (nu pe LH). Testosteronul inhibă atât LH cât și GnRH. Inhibina este marker al funcției spermatogenice: inhibina ↓ → FSH ↑ → semn de afectare a spermatogenezei.
❌ Greșit. Inhibina (de la celulele Sertoli) inhibă SELECTIV FSH. Testosteronul inhibă LH + GnRH. Aceasta este o distincție importantă la admitere!

8. Criptorhidia poate duce la infertilitate deoarece:

A Absența scrotului blochează fizic spermatogeneza
B Temperatura abdominală (~37°C) este prea ridicată pentru spermatogeneză normală ✓
C Testiculul necoborât nu este vascularizat
D Lipsesc celulele Leydig în testiculul necoborât
✅ Corect! Criptorhidia = testicul(e) necoborât(e). Spermatogeneza necesită temperatura mai mică cu 2-3°C față de temperatura abdominală. La 37°C → spermatogeneza este inhibată → infertilitate. Tratament: orchidopexie sau hormoni (hCG, GnRH). Risc crescut de cancer testicular!
❌ Greșit. Criptorhidia cauzează infertilitate deoarece temperatura abdominală (~37°C) este prea ridicată pentru spermatogeneză normală, care necesită ~34-35°C.

9. Ce se întâmplă în Profaza I a meiozei ce NU se întâmplă în mitoză?

A Condensarea cromozomilor
B Formarea fusului de diviziune
C Sinapsis (tetradă) + Crossing-over (variabilitate genetică) ✓
D Replicarea ADN
✅ Corect! Profaza I a meiozei este unică prin sinapsis (perechile de cromozomi omologi se aliniază → tetradă) și crossing-over (schimb de segmente de cromatide între cromozomi omologi → variabilitate genetică). Aceasta NU se întâmplă în mitoză!
❌ Greșit. Evenimentul unic al Profazei I este sinapsis + crossing-over (recombinare genetică). Condensarea și fusul apar și în mitoză. Replicarea ADN are loc în interfaza premiotică.

10. Erecția penisului este controlată de sistemul nervos:

A Simpatic (T12-L2)
B Parasimpatic (S2-S4) ✓
C Somatic (nervul pudendal)
D Somatic (nervul iliohipogastric)
✅ Corect! Erecție = PARASIMPATIC (S2-S4): nervii cavernosi → NO → vasodilatație arteriole → umplere sinusoide. Mnemonic: "Point = Parasimpatic". Ejacularea = SIMPATIC (T12-L2). Mnemonic: "Shoot = Simpatic".
❌ Greșit. Erecția este controlată de sistemul PARASIMPATIC (S2-S4) prin eliberare de NO → vasodilatație. Simpatic (T12-L2) controlează ejacularea.

11. Vasectomia (ligaturarea ductului deferent) afectează ejaculatul astfel:

A Elimină complet ejaculatul (volum zero)
B Reduce ejaculatul cu 60%
C Elimină spermatozoizii dar volumul rămâne aproape neschimbat (~95%) ✓
D Reduce ejaculatul cu 30% (secretia prostatică se pierde)
✅ Corect! Spermatozoizii reprezintă doar ~5% din volumul seminal. Glandele (vezicula seminală 60% + prostata 30% + bulbouretrale 5%) continuă să secrete. Deci vasectomia elimină spermatozoizii dar volumul ejaculat rămâne ~95% din cel inițial.
❌ Greșit. Vasectomia elimină spermatozoizii (5% din volum). Celelalte glande continuă să secrete, deci volumul rămâne ~95% din normal. Spermograma post-vasectomie: volum normal, 0 spermatozoizi.

12. Care structură spermatozoidului conține mitocondrii și produce ATP pentru motilitate?

A Capul (nucleul)
B Piesa intermediară ✓
C Acrozomul
D Coada (flagelul)
✅ Corect! Piesa intermediară conține mitocondrii dispuse în spirală → produc ATP → energie pentru mișcările flagelului (cozii). Capul = nucleu (23 cromozomi) + acrozom (enzime fertilizare); Coada = axonemă + propulsie.
❌ Greșit. Piesa intermediară conține mitocondrii → ATP → mișcarea cozii. Capul = nucleu + acrozom; Acrozomul = enzime fertilizare (nu mitocondrii).
